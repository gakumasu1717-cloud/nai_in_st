# NaiStudio

SillyTavern 안에서 쓰는 NovelAI 브라우저 + 그림체 라이브러리.

이미지를 드롭하면 PNG 메타데이터를 읽어 프롬프트·UC·캐릭터 프롬프트·파라미터를 그대로 복원하고,
그 상태를 **그림체**로 저장해뒀다가 언제든 다시 꺼내 쓸 수 있습니다.
패널 안에서 태그를 고쳐가며 계속 뽑고, 마음에 드는 결과는 채팅에 바로 삽입합니다.

## 설치

### 1) 확장 (필수)

이 폴더 전체를 다음 위치에 복사합니다.

```
SillyTavern/public/scripts/extensions/third-party/NaiStudio/
```

`server-plugin/` 하위는 확장 쪽에서 쓰지 않으므로 남겨둬도 무방합니다.

### 2) 서버 플러그인 (권장)

없어도 동작하지만, **캐릭터 프롬프트 / Vibe Transfer / cfg_rescale / 시드 고정**을 쓰려면 필요합니다.

```
SillyTavern/plugins/naistudio/index.mjs      ← server-plugin/index.mjs
SillyTavern/plugins/naistudio/package.json   ← server-plugin/package.json
```

그리고 `config.yaml` 에서:

```yaml
enableServerPlugins: true
```

ST를 재시작한 뒤 패널 우상단 배지가 `백엔드: NaiStudio 플러그인` 이면 정상입니다.

## 백엔드 3단 폴백

| 순서 | 경로 | 지원 범위 |
| --- | --- | --- |
| 1 | `/api/plugins/naistudio/generate-image` | 전부 (캐릭터·바이브·레퍼런스·rescale·시드) |
| 2 | `/api/plugins/autopic/generate-image` | 거의 전부 (AutoPic 서버 플러그인 재사용) |
| 3 | `/api/novelai/generate-image` | 기본 파라미터만. 캐릭터 프롬프트·바이브는 무시됨 |

404가 뜬 백엔드는 자동으로 건너뛰고 다음 단계로 내려갑니다.
설정 탭에서 특정 백엔드로 고정할 수도 있습니다.

**탐지 방식**: 자체 플러그인은 `GET /ping` 으로, AutoPic은 `POST /favorite-vibe` 에 빈 body를 보내
확인합니다. AutoPic의 `generate-image` 로 찌르면 진짜 생성이 돌아가 과금되지만, `favorite-vibe` 는
image가 없으면 아무것도 바꾸지 않고 400을 돌려주므로 안전합니다.
`/favorite-vibe` 가 없는 구버전 AutoPic은 404가 떠서 탐지되지 않는데, 이때는 '없음'이 아니라
'확인 불가'로 표시하고 생성 시 실제 폴백에 맡깁니다. 설정에서 백엔드를 **AutoPic**으로 직접 고정해도 됩니다.

## 기능

### 그림체 저장/불러오기
- 그림체 탭의 **`이미지로 추가`** 버튼 = 사진을 고르면 메타데이터를 읽어 바로 그림체 편집기가 열립니다.
  (`JSON 가져오기`는 다른 기기에서 내보낸 그림체 묶음을 불러올 때 씁니다)
- 생성 탭에 이미지를 드롭해서 `그림체로 저장` 해도 됩니다
- 카드 그리드에서 검색/태그 필터/즐겨찾기
- 그림체를 저장할 때 **무엇을 같이 담을지** 개수와 함께 골라 담습니다.
  (`파라미터 832×1216 · 28steps` / `캐릭터 프롬프트 2명 — 유키, 하루` / `레퍼런스·바이브 1장`)
  드롭한 이미지에 캐릭터 정보가 없으면 지금 패널에 있는 캐릭터가 대신 담깁니다.
- `적용` 하나로 태그·UC·파라미터·캐릭터·소스를 한 번에 불러옵니다.
  (guidance 같은 파라미터가 그림체마다 다르므로 태그만 따로 적용하는 버튼은 없앴습니다)
- 지금 적용된 그림체는 패널 상단에 칩으로 표시되며, X를 누르면 **그 그림체가 넣었던 태그만** 프롬프트에서 빠집니다.
  다른 그림체를 적용하면 이전 그림체 태그는 자동으로 교체됩니다.
- `ST 스타일` 버튼으로 SillyTavern 기본 이미지생성 확장(`extension_settings.sd.styles`)의
  스타일을 `[ST] 이름` 으로 가져올 수 있습니다. `{prompt}` 자리표시자는 제거됩니다.
- JSON 내보내기·가져오기로 다른 기기와 공유

### 캐릭터 위치
NovelAI 공식 클라이언트는 캐릭터 좌표로 **5×5 격자(0.1 / 0.3 / 0.5 / 0.7 / 0.9)** 만 사용합니다.
그래서 NaiStudio도 같은 격자 선택기를 쓰고, 저장돼 있던 임의의 값(예: 0.35)은 전송 직전과
서버 양쪽에서 가장 가까운 격자점으로 스냅합니다. `위치 지정` 체크를 끄면 좌표를 보내지 않고
NAI가 알아서 배치합니다(`use_coords: false`).

### 메타데이터 읽기
- NovelAI `tEXt`/`iTXt`/`zTXt` (Comment JSON, v4 char_captions + centers 포함)
- NovelAI **stealth** 알파채널 LSB (tEXt가 제거된 이미지)
- A1111 `parameters`, ComfyUI workflow(프롬프트 회수 수준)

읽지 못했을 때는 **왜 못 읽었는지** 알려줍니다 — PNG가 아닌 경우(사진 앱·메신저를 거치며 JPEG로 변환되면
NovelAI 정보가 사라집니다), PNG지만 텍스트 청크가 지워진 경우, 형식이 다른 경우를 구분해서 표시합니다.

### 뷰어
생성 결과는 패널 위쪽 대형 뷰어에 바로 크게 뜹니다. NAI 브라우저와 비슷한 동작:

- 이미지는 패널 폭을 꽉 채우고 높이는 비율대로 늘어납니다 (겹치는 오버레이 없음)
- **이미지를 누르면 크게 보기**, 실제 동작은 전부 아래 버튼 줄에 있습니다
- 아래는 두 줄로 나뉩니다 — 위: `‹ 1/3 · seed · 저장됨 ›`, 아래: 라벨이 붙은 동작 버튼들

| 버튼 | 하는 일 |
| --- | --- |
| 저장 | 이 이미지를 기기에 다운로드 |
| 채팅에 넣기 | 열려 있는 채팅에 이미지 메시지로 삽입 |
| 시드 가져오기 | 이 이미지의 시드를 시드 칸에 넣어 같은 구도로 다시 뽑기 |
| 설정 되돌리기 | 이 이미지를 뽑을 때 쓴 프롬프트·캐릭터·파라미터를 전부 복원 |
| 그림체로 저장 | 이 이미지를 그림체 프리셋으로 저장 |
| 바이브로 등록 | Vibe Transfer 소스로 등록 |
| 목록에서 빼기 | 갤러리 목록에서만 제거 (저장된 파일은 그대로) |

생성 버튼은 팝업의 **'닫기' 버튼과 같은 줄**에 고정되어, 어떤 탭에 있든 스크롤과 무관하게 항상 눌립니다.

생성 바가 화면 아래쪽에 있어 토스트 알림과 겹치므로, **패널이 열려 있는 동안에만** 토스트를 화면 위쪽으로 올립니다
(`body.ss-panel-open #toast-container`). 패널을 닫으면 ST 원래 위치로 되돌아가며, 다른 확장의 알림 위치에는 영향을 주지 않습니다.

### 접기
`이미지에서 불러오기 · 프롬프트 · 네거티브 · 캐릭터 프롬프트 · 생성 설정 · Vibe Transfer · Director Reference`
는 제목을 눌러 접을 수 있습니다. 접힘 상태는 저장되어 다음에 열 때도 유지됩니다.

접힌 섹션에는 안에 뭐가 들었는지 요약 뱃지가 붙습니다(`2명`, `3장`, `832×1216 · 28steps` 등).
Vibe / Director Reference는 접어도 **사용 체크박스는 헤더에 남아** 있어서 펼치지 않고 켜고 끌 수 있습니다.

### 생성 패널
- 프롬프트 / UC / 캐릭터별 프롬프트·UC·좌표
- 모델·해상도·steps·guidance·rescale·sampler·scheduler·시드·SMEA·Variety+·Decrisper
- **시드 `-1` = 랜덤**(기본값). 특정 숫자를 넣으면 그 시드로 고정됩니다.
  주사위 버튼은 -1로 되돌리고, 자물쇠 버튼은 마지막 결과의 시드를 넣습니다.
- 이미지를 드롭했을 때 고를 수 있는 것: **전부 적용 · 그림체로 저장 · 바이브 · 캐릭터 레퍼런스**

### 레퍼런스
**레퍼런스 탭 한 곳**에서 전부 관리합니다. 목록 맨 위가 `그림 전체`,
그 아래로 등록된 캐릭터 수만큼 슬롯이 자동으로 생깁니다.
(캐릭터 카드 안에 두면 모바일에서 카드가 너무 길어져서 옮겼습니다. 카드에는 레퍼런스가 붙었다는 뱃지만 표시됩니다)

캐릭터에 붙인 레퍼런스는 서버에서 그 캐릭터의 `char_caption`/좌표에 묶여 나가므로 "이 얼굴은 이 캐릭터" 로 해석됩니다.
전체 + 캐릭터 합쳐 최대 4장이며, 초과분은 경고와 함께 잘립니다.
모든 레퍼런스는 전송 전에 NAI가 허용하는 캔버스(1024×1536 / 1536×1024 / 1472×1472)로 자동 레터박싱됩니다.

### 헬퍼
- **태그 자동완성** (기본 danbooru 태그 + 저장된 그림체/히스토리에서 학습)
- **가중치 조절** `Ctrl+↑/↓` — v4는 `1.1::tag::`, v3는 `{tag}`/`[tag]`
- **태그 정리** 중복 제거·공백 정규화
- `Ctrl+Enter` 생성

### 갤러리
생성 결과마다: 채팅 삽입 · 다운로드 · 설정 복원 · 시드 재사용 · 그림체로 저장 · 바이브로 등록.
갤러리에서 이미지를 누르면 생성 탭 뷰어로 보내집니다.

### 모바일
가로 스크롤이 생기지 않도록 만들었습니다 — 탭은 2줄로 접히고, 빠른 그림체·썸네일은 줄바꿈 그리드,
목록은 1~2열, 캐릭터 카드는 레퍼런스가 위로 올라가는 세로 배치가 됩니다.
입력창은 16px(iOS 자동 확대 방지), 터치 타겟은 34px 이상입니다.

## Anlas(유료 크레딧) 아끼기

**중요**: SillyTavern 기본 이미지생성 확장의 `Avoid Anlas cost` 설정은 **그 확장 안에서만** 동작합니다.
ST 서버 엔드포인트(`src/endpoints/novelai.js`)에는 anlas 관련 로직이 전혀 없고, steps/해상도를 그대로 NAI에 넘깁니다.
NaiStudio는 SD 확장을 거치지 않으므로 **ST의 가드가 적용되지 않습니다.** 그래서 자체 가드를 넣었습니다.

설정 탭의 `Anlas 아끼기`(기본 켜짐)를 켜면 생성 직전에 무료 조건으로 낮춥니다.

| 항목 | 무료 조건 | 가드 동작 |
| --- | --- | --- |
| 해상도 | 1,048,576픽셀 이하 | 비율 유지하며 64의 배수로 축소 |
| steps | 28 이하 | 28로 제한 |
| 업스케일 | 사용 시 Anlas 소모 | 해제 |
| v4 Vibe 인코딩 | 인코딩마다 Anlas 소모 | **건드리지 않고 경고만** (결과가 달라지므로) |

생성 바에 현재 설정이 `무료 조건` / `Anlas 소모` 로 항상 표시되고, 조정이 일어나면 무엇을 낮췄는지 알려줍니다.
(예: `1536×1536, steps 50` → 실제 전송 `1024×1024, steps 28`)

## 생성한 이미지는 어디로 가나

**채팅방을 열어뒀든 아니든 항상 같은 곳**에 저장됩니다.

```
user/images/NaiStudio/ss_<시드>_<타임스탬프>.png
```

폴더 이름은 설정 탭에서 바꿀 수 있습니다. ST의 이미지 저장 API는 원래 캐릭터 이름으로 폴더를 나누지만,
NaiStudio는 채팅 상태와 무관하게 고정 폴더 하나만 씁니다.

- **자동 저장(기본 켜짐)**: 생성 즉시 파일로 떨어집니다. 패널을 닫아도 남습니다.
- **채팅 삽입**: 이미 저장된 그 파일을 참조하므로 사본이 생기지 않습니다.
  채팅이 열려 있지 않으면 삽입만 건너뛰고, 파일은 그대로 남습니다.
- **자동 저장을 끄면** 이미지가 메모리에만 있다가 패널을 닫는 순간 사라집니다.
  (갤러리에서 개별 저장/다운로드는 여전히 가능)

## 데이터 위치

모든 설정·그림체·히스토리는 `extension_settings.NaiStudio` 에 저장되어 ST 설정과 함께 서버에 남습니다.
썸네일은 192px webp로 축소해 저장하지만, 그림체가 많아지면 설정 파일이 커질 수 있습니다.
바이브 이미지 원본(base64)은 그림체에 "소스 포함"으로 저장할 때만 들어갑니다.
