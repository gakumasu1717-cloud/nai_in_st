# StyleStudio

SillyTavern 안에서 쓰는 NovelAI 브라우저 + 그림체 라이브러리.

이미지를 드롭하면 PNG 메타데이터를 읽어 프롬프트·UC·캐릭터 프롬프트·파라미터를 그대로 복원하고,
그 상태를 **그림체**로 저장해뒀다가 언제든 다시 꺼내 쓸 수 있습니다.
패널 안에서 태그를 고쳐가며 계속 뽑고, 마음에 드는 결과는 채팅에 바로 삽입합니다.

## 설치

### 1) 확장 (필수)

이 폴더 전체를 다음 위치에 복사합니다.

```
SillyTavern/public/scripts/extensions/third-party/StyleStudio/
```

`server-plugin/` 하위는 확장 쪽에서 쓰지 않으므로 남겨둬도 무방합니다.

### 2) 서버 플러그인 (권장)

없어도 동작하지만, **캐릭터 프롬프트 / Vibe Transfer / cfg_rescale / 시드 고정**을 쓰려면 필요합니다.

```
SillyTavern/plugins/stylestudio/index.mjs      ← server-plugin/index.mjs
SillyTavern/plugins/stylestudio/package.json   ← server-plugin/package.json
```

그리고 `config.yaml` 에서:

```yaml
enableServerPlugins: true
```

ST를 재시작한 뒤 패널 우상단 배지가 `백엔드: StyleStudio 플러그인` 이면 정상입니다.

## 백엔드 3단 폴백

| 순서 | 경로 | 지원 범위 |
| --- | --- | --- |
| 1 | `/api/plugins/stylestudio/generate-image` | 전부 (캐릭터·바이브·레퍼런스·rescale·시드) |
| 2 | `/api/plugins/autopic/generate-image` | 거의 전부 (AutoPic 서버 플러그인 재사용) |
| 3 | `/api/novelai/generate-image` | 기본 파라미터만. 캐릭터 프롬프트·바이브는 무시됨 |

404가 뜬 백엔드는 자동으로 건너뛰고 다음 단계로 내려갑니다.
설정 탭에서 특정 백엔드로 고정할 수도 있습니다.

## 기능

### 그림체 저장/불러오기
- 이미지 드롭 → 메타데이터 파싱 → `그림체로 저장`
- 카드 그리드에서 검색/태그 필터/즐겨찾기
- 적용 모드: **전부**(태그+파라미터+캐릭터+소스) / **태그만** 병합
- 지금 적용된 그림체는 패널 상단에 칩으로 표시되며, X를 누르면 **그 그림체가 넣었던 태그만** 프롬프트에서 빠집니다.
  다른 그림체를 적용하면 이전 그림체 태그는 자동으로 교체됩니다.
- `ST 스타일` 버튼으로 SillyTavern 기본 이미지생성 확장(`extension_settings.sd.styles`)의
  스타일을 `[ST] 이름` 으로 가져올 수 있습니다. `{prompt}` 자리표시자는 제거됩니다.
- JSON 내보내기·가져오기로 다른 기기와 공유

### 캐릭터 위치
NovelAI 공식 클라이언트는 캐릭터 좌표로 **5×5 격자(0.1 / 0.3 / 0.5 / 0.7 / 0.9)** 만 사용합니다.
그래서 StyleStudio도 같은 격자 선택기를 쓰고, 저장돼 있던 임의의 값(예: 0.35)은 전송 직전과
서버 양쪽에서 가장 가까운 격자점으로 스냅합니다. `위치 지정` 체크를 끄면 좌표를 보내지 않고
NAI가 알아서 배치합니다(`use_coords: false`).

### 메타데이터 읽기
- NovelAI `tEXt`/`iTXt`/`zTXt` (Comment JSON, v4 char_captions + centers 포함)
- NovelAI **stealth** 알파채널 LSB (tEXt가 제거된 이미지)
- A1111 `parameters`, ComfyUI workflow(프롬프트 회수 수준)

### 뷰어
생성 결과는 패널 위쪽 대형 뷰어에 바로 크게 뜹니다. NAI 브라우저와 비슷한 동작:

- **이미지를 누르면 즉시 파일로 저장**(다운로드)
- 좌우 화살표 / 아래 썸네일로 이전 결과 넘기기
- 우클릭(길게 누르기)하면 프롬프트까지 원본 크기로 확대
- 뷰어 아래 줄에서 채팅 삽입 · 시드 재사용 · 설정 복원 · 그림체로 저장 · 바이브 등록

생성 버튼은 팝업의 **'닫기' 버튼과 같은 줄**에 고정되어, 어떤 탭에 있든 스크롤과 무관하게 항상 눌립니다.

생성 바가 화면 아래쪽에 있어 토스트 알림과 겹치므로, **패널이 열려 있는 동안에만** 토스트를 화면 위쪽으로 올립니다
(`body.ss-panel-open #toast-container`). 패널을 닫으면 ST 원래 위치로 되돌아가며, 다른 확장의 알림 위치에는 영향을 주지 않습니다.

### 생성 패널
- 프롬프트 / UC / 캐릭터별 프롬프트·UC·좌표
- 모델·해상도·steps·guidance·rescale·sampler·scheduler·시드·SMEA·Variety+·Decrisper
- **`N장 연속`** 버튼 = 같은 설정으로 N장을 연달아 뽑습니다.
  시드를 비워두면 매번 랜덤, 시드를 고정해두면 시드가 1씩 올라가며 변주가 나옵니다.
  생성 중에 생성 버튼을 다시 누르면 남은 장수를 취소합니다.
- 이미지를 드롭했을 때 고를 수 있는 것: **전부 적용 · 그림체로 저장 · 바이브 · 캐릭터 레퍼런스**

### 레퍼런스
전역 레퍼런스(레퍼런스 탭)와 캐릭터별 레퍼런스(생성 탭의 캐릭터 카드)는 **한 요청에 함께** 전송됩니다.
캐릭터에 붙인 레퍼런스는 서버에서 그 캐릭터의 `char_caption`/좌표에 묶여 나가므로 "이 얼굴은 이 캐릭터" 로 해석됩니다.
전역 + 캐릭터 합쳐 최대 4장이며, 초과분은 경고와 함께 잘립니다.
모든 레퍼런스는 전송 전에 NAI가 허용하는 캔버스(1024×1536 / 1536×1024 / 1472×1472)로 자동 레터박싱됩니다.

### 헬퍼
- **와일드카드** `__이름__` — 생성할 때마다 등록된 목록 중 하나가 그 자리에 무작위로 들어갑니다.
  그림체는 고정하고 조명·포즈·배경만 굴릴 때 씁니다. (설정 탭에서 편집)
- **인라인 랜덤** `{a|b|c}`, `{2$$a|b|c}` (3개 중 2개 뽑기) — 한 번만 쓸 변주는 등록 없이 이쪽이 편합니다.
- **태그 자동완성** (기본 danbooru 태그 + 저장된 그림체/히스토리에서 학습)
- **가중치 조절** `Ctrl+↑/↓` — v4는 `1.1::tag::`, v3는 `{tag}`/`[tag]`
- **태그 정리** 중복 제거·공백 정규화
- `Ctrl+Enter` 생성

### 갤러리
생성 결과마다: 채팅 삽입 · 다운로드 · 설정 복원 · 시드 재사용 · 그림체로 저장 · 바이브로 등록.
갤러리에서 이미지를 누르면 생성 탭 뷰어로 보내집니다.

### 모바일
가로 스크롤이 생기지 않도록 만들었습니다 — 탭은 2줄로 접히고, 빠른 그림체·썸네일은 줄바꿈 그리드,
목록은 1~2열, 캐릭터 카드는 레퍼런스가 위로 올라가는 세로 배치가 됩니다.
입력창은 16px(iOS 자동 확대 방지), 터치 타겟은 34px 이상입니다.

| 커맨드 | 설명 |
| --- | --- |
| `/ssopen` | 패널 열기 |

## 생성한 이미지는 어디로 가나

**채팅방을 열어뒀든 아니든 항상 같은 곳**에 저장됩니다.

```
user/images/StyleStudio/ss_<시드>_<타임스탬프>.png
```

폴더 이름은 설정 탭에서 바꿀 수 있습니다. ST의 이미지 저장 API는 원래 캐릭터 이름으로 폴더를 나누지만,
StyleStudio는 채팅 상태와 무관하게 고정 폴더 하나만 씁니다.

- **자동 저장(기본 켜짐)**: 생성 즉시 파일로 떨어집니다. 패널을 닫아도 남습니다.
- **채팅 삽입**: 이미 저장된 그 파일을 참조하므로 사본이 생기지 않습니다.
  채팅이 열려 있지 않으면 삽입만 건너뛰고, 파일은 그대로 남습니다.
- **자동 저장을 끄면** 이미지가 메모리에만 있다가 패널을 닫는 순간 사라집니다.
  (갤러리에서 개별 저장/다운로드는 여전히 가능)

## 데이터 위치

모든 설정·그림체·히스토리는 `extension_settings.StyleStudio` 에 저장되어 ST 설정과 함께 서버에 남습니다.
썸네일은 192px webp로 축소해 저장하지만, 그림체가 많아지면 설정 파일이 커질 수 있습니다.
바이브 이미지 원본(base64)은 그림체에 "소스 포함"으로 저장할 때만 들어갑니다.
